
# COVID-19 Data Analysis Project

## About This Project

This project analyzes COVID-19 data at the country level using Python.
It focuses on understanding confirmed cases, deaths, recoveries,
and regional impact.

The goal is to explore patterns and gain basic insights
using data analysis and visualization.

---

## Dataset

The dataset contains country-wise COVID-19 information such as:

- Confirmed cases
- Deaths
- Recovered cases
- Active cases
- WHO Region

Each row represents one country.

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## What I Did

- Explored and cleaned the data
- Analyzed top affected countries
- Compared recovery and death rates
- Studied regional impact
- Created visualizations
- Checked correlations

---

## Key Findings

- Higher confirmed cases are linked to higher deaths.
- Recovery rates differ across countries.
- Some regions were more affected than others.

---

## Conclusion

This project helped me understand how COVID-19 data can be analyzed
using Python and visualization techniques.
